Welcome to Mile Assistant!

--------------------------------------------------------------------------------
1. QUICK START
--------------------------------------------------------------------------------
1. Extract ALL files in this zip into a single folder on your PC.
   CRITICAL: Do NOT run mile.exe from inside the ZIP file. All DLLs must
   stay in the same folder as mile.exe.

2. Create Your Account:
   - If your host provided a web portal link, open "Account_Portal.html" in
     your browser to register your username and password.
   - Or ask the administrator to create your account in the Supabase users table.

3. Launch:
   - Right-click `mile.exe` and select "Run as Administrator" (recommended
     for global hotkeys and overlay capture).
   - If Windows Defender SmartScreen appears ("Windows protected your PC"):
     Click "More info" -> "Run anyway".

4. Log in:
   - Type your Username and Password and press ENTER (or click LOG IN).
   - API keys and your tier settings will be fetched automatically.

--------------------------------------------------------------------------------
2. DEFAULT HOTKEYS (Configured in hotkeys.json)
--------------------------------------------------------------------------------
* Toggle Overlay Show/Hide : Alt + O (or your configured shortcut)
* Focus Chat Input        : Ctrl + Space / Enter
* Stealth Mode            : Enabled by default

--------------------------------------------------------------------------------
3. FILES INCLUDED
--------------------------------------------------------------------------------
* mile.exe           - Main Application
* Dll1.dll           - Input Hook & Stealth Hook Library
* WebView2Loader.dll - Edge WebView2 Component
* msvcp140.dll       - VC++ Runtime
* vcruntime140.dll   - VC++ Runtime
* vcruntime140_1.dll - VC++ Runtime
* hotkeys.json       - Hotkeys & Interface Configuration
* Account_Portal.html- Web registration portal
